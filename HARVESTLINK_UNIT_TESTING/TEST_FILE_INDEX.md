# HarvestLink test file index

The index includes all test files in the three configured suites. It includes unit tests, source-level presentation checks, HTTP and socket integration tests, and SQL migration tests.

From the repository root, run `npm.cmd run test:all` in Windows PowerShell. Use `npm.cmd run test:vitest` for the dedicated unit suite or `npm.cmd run test:coverage` for its V8 report. The coverage command updates the repository's existing coverage directory.
